# موقع حِسبة التعريفي

Landing page عربية مستقلة لعرض نظام حِسبة واستقبال طلبات العملاء عبر واتساب.

## المعاينة محليًا

من مجلد `website` شغّل أي static server، مثل:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## ضبط واتساب المبيعات

افتح `index.html` وضع رقم واتساب بصيغة دولية، بدون `+` أو مسافات، في الخاصية التالية:

```html
<body data-whatsapp="201001234567">
```

إذا تُرك الرقم فارغًا، سيفتح واتساب برسالة جاهزة ويطلب من الزائر اختيار المحادثة.

## الفيديو التعريفي

الفيديو النهائي وصورة الغلاف والترجمة العربية موجودة داخل `media/`. لإعادة بنائه بعد تعديل النص أو الصور:

```bash
./video-src/build-video.sh
```

يتطلب البناء `ffmpeg` وصوت macOS العربي `Majed`. سكربت توليد الشرائح ومحتوى التعليق الصوتي موجودان داخل `video-src/`.

## النشر

المجلد لا يحتاج build step. ارفع محتويات `website/` كما هي على Cloudflare Pages أو Netlify أو GitHub Pages أو أي استضافة ملفات ثابتة.
